# Retired Automation engine decision

The proposed OpenWorkflow adoption and Host Automation module were withdrawn in WVE-67 under WVE-66. Weave retains ordinary ACP Agent Turns, durable Thread recovery, and persistent terminals; it has no Automation engine. The user chose an Alpha-only product with a Bun Host, Electron desktop, and Capacitor iPad before the terminal-first work in WVE-65. The earlier proposal is retained in canceled WVE-64, not as an active implementation requirement.
