# Domain documentation

Read the root `CONTEXT.md` glossary and `docs/adr/` before changing domain terminology or architecture. Use a `CONTEXT-MAP.md` if multiple maintained contexts are introduced; do not recreate the retired application's module tree merely to follow an old map.

The supported implementation is `product/alpha`, `product/portal`, and `product/protocol`. `product/deferred` holds historical snapshots and is not an active bounded context. Retired ADRs and dated research are evidence, not current implementation requirements. Use the domain-modeling skill when changing the glossary or recording a decision.
