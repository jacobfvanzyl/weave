# Native terminal fonts

Unmodified JetBrains Mono Nerd Font Regular, Bold, Italic, and BoldItalic TTFs,
from the pinned Ghostty source revision
`4a70ee4718ba0967bcfd72f43adb715bf65a860d`, `src/font/res/`.

Source: https://github.com/ghostty-org/ghostty/tree/4a70ee4718ba0967bcfd72f43adb715bf65a860d/src/font/res

The accompanying `OFL.txt` is copied from that same directory. These files are
bundled as native resources and registered with CoreText on macOS and iPadOS;
the web shell's WOFF2 fonts do not supply native glyphs.
