# Deferred Alpha surfaces

WVE-68 removed filetree, dedicated Editor, and embedded Browser from the active Alpha and Host application. These source and fixture snapshots are reference material only: they are not an installable package, build input, supported API, or test suite. Relative imports describe the original placement and are not maintained. Use Git history for a coherent historical checkout.

Browser reintroduction needs a separate design after WVE-65. Do not re-register these providers or native bridges to satisfy a stale persisted layout. The live application keeps xterm.js, ACP, Workspace registration, and the Host filesystem operations agents need.
