# webSearch

## Description

Search the web with Exa for current or external information. Returns relevant results with URLs, snippets, optional summaries, and optional full text.

## Inputs

### query

Search query.

### maxResults

Maximum results to return.

### includeText

Include cleaned page text in each result.

### includeSummary

Include Exa-generated summaries in each result.

### includeHighlights

Include relevant highlights in each result.

### includeDomains

Restrict search to these domains.

### excludeDomains

Exclude these domains.

### timeRange

Filter by recency.
